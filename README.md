
# SalesPilot - 営業管理Webアプリ

## 概要

SalesPilotは、顧客情報と商談情報を一元管理するための営業管理Webアプリケーションです。

自動車販売の営業職として培った経験をもとに、顧客情報の整理や商談の進捗管理を効率化したいと考え、JavaとSpring Bootを使用して個人開発しました。

## 開発目的

営業活動では、顧客ごとの商談履歴や進捗状況を正確に把握することが重要です。

そこで、顧客管理・商談管理・売上状況の可視化を一つのシステムで行えるアプリケーションを目指しました。

## 主な機能

### 顧客管理
- 顧客の新規登録・一覧表示・編集・削除
- 顧客名・会社名による検索
- 顧客ごとの商談履歴表示
- 商談が紐づく顧客の削除防止
- 必須項目の入力チェック

### 商談管理
- 商談の新規登録・一覧表示・編集・削除
- 商談名による検索
- 進捗状況による絞り込み
- 商談名と進捗状況の組み合わせ検索
- 商談金額・予定日・メモの管理
- 顧客情報と商談情報の紐づけ
- 入力内容のチェック

### ダッシュボード
- 顧客件数の表示
- 商談件数の表示
- 受注件数の表示
- 受注金額の集計
- 進捗状況別の件数表示

## 工夫した点

### 1. 営業経験を活かした機能設計
実際の営業活動を想定し、顧客ごとの商談履歴や進捗状況を確認できるようにしました。

### 2. データの整合性を意識した実装
商談が登録されている顧客を誤って削除しないように、削除防止処理を実装しました。

### 3. 検索・絞り込み機能
商談名と進捗状況を組み合わせて検索できるようにし、必要な情報を探しやすくしました。

### 4. ダッシュボードによる可視化
顧客数や受注金額、進捗状況別の件数を集計し、営業状況を把握しやすくしました。

### 5. 入力チェック
必須項目や商談金額の入力チェックを実装し、不正なデータ登録を防止しました。

## ローカルでの起動方法

1. Java 17を用意します。
2. リポジトリをクローンします。
3. EclipseでMavenプロジェクトとしてインポートします。
4. Spring Bootアプリケーションを起動します。
5. ブラウザで http://localhost:8080 にアクセスします。

※ データベースにはH2を使用しています。ローカル環境で起動すると、設定された保存先にデータが作成されます。
